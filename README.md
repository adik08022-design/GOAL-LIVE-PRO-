# GOAL LIVE PRO

Android prototype for Android 10+.

## Build
GitHub Actions runs the debug APK build on pushes to `main`. The APK is published as the workflow artifact `GOAL-LIVE-PRO-APK`.

## Current prototype limitations
- Score feed currently points to ESPN's English Premier League scoreboard endpoint only.
- Refresh is manual.
- Floating overlay is a placeholder and does not yet stream match scores.
- This is not yet the requested all-leagues live-score release.
